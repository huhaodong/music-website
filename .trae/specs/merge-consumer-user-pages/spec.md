# 合并用户管理页面 Spec

## Why
当前系统存在两个功能重叠的用户管理页面：`/Consumer`（旧用户管理）和 `/Home/user`（RBAC用户管理）。两个页面都展示用户信息，但各自包含对方没有的功能。需要合并为一个统一的用户管理页面，保留所有现有功能。

## What Changes
- 创建新的统一用户管理页面，合并两个页面的所有功能
- 侧边栏菜单统一为 `/Home/user` 路径
- 移除冗余的 `/Consumer` 路由和菜单项
- 更新相关跳转逻辑

## Impact
- Affected specs: 用户管理功能
- Affected code:
  - 新建 `src/views/UnifiedUserPage.vue` 合并页面
  - 修改 `src/router/index.ts` 路由配置
  - 修改 `src/components/layouts/YinAside.vue` 侧边栏菜单
  - 可能删除 `src/views/ConsumerPage.vue`

## ADDED Requirements

### Requirement: 统一用户管理页面
系统 SHALL 提供一个统一的用户管理页面，整合 `/Consumer` 和 `/Home/user` 的所有功能。

#### Scenario: 查看用户列表
- **WHEN** 用户访问用户管理页面
- **THEN** 显示包含以下列的表格：ID、用户头像、用户名、昵称、性别、手机号码、邮箱、生日、签名、地区、角色、状态、创建时间

#### Scenario: 搜索和筛选用户
- **WHEN** 用户在搜索框输入关键词或选择角色筛选
- **THEN** 表格实时过滤显示匹配的用户

#### Scenario: 添加用户
- **WHEN** 用户点击"添加用户"按钮
- **THEN** 弹出对话框，用户可输入用户名、昵称、密码、邮箱、手机号、选择角色和状态

#### Scenario: 编辑用户
- **WHEN** 用户点击某行的"编辑"按钮
- **THEN** 弹出对话框，用户可编辑该用户的昵称、邮箱、手机号、状态

#### Scenario: 分配角色
- **WHEN** 用户点击某行的"分配角色"按钮
- **THEN** 弹出对话框，用户可为该用户勾选角色

#### Scenario: 删除用户
- **WHEN** 用户点击某行的"删除"按钮或选择多行后点击"批量删除"
- **THEN** 弹出确认对话框，确认后删除用户

#### Scenario: 更新用户头像
- **WHEN** 用户点击某行的"更新头像"按钮
- **THEN** 弹出文件选择框，选择图片后上传更新该用户的头像

#### Scenario: 查看用户收藏
- **WHEN** 用户点击某行的"收藏"按钮
- **THEN** 跳转到收藏信息页面，显示该用户的收藏列表

## MODIFIED Requirements

### Requirement: 侧边栏菜单
将原有的"用户管理"菜单项从独立菜单项合并到"系统管理"子菜单中，统一指向 `/Home/user`。

### Requirement: 路由配置
移除 `/Consumer` 路由，所有用户管理功能统一通过 `/Home/user` 访问。

## REMOVED Requirements

### Requirement: ConsumerPage.vue
**Reason**: 页面功能已合并到新的统一用户管理页面
**Migration**: 功能迁移到新的统一页面后删除此文件

## 功能跳转逻辑

| 源页面 | 操作 | 目标页面/行为 |
|--------|------|---------------|
| 统一用户管理页 | 点击"添加用户" | 弹出添加用户对话框 |
| 统一用户管理页 | 点击"编辑" | 弹出编辑用户对话框 |
| 统一用户管理页 | 点击"分配角色" | 弹出角色分配对话框 |
| 统一用户管理页 | 点击"删除" | 弹出确认对话框 |
| 统一用户管理页 | 点击"更新头像" | 触发文件上传 |
| 统一用户管理页 | 点击"收藏" | 跳转到 `/Collect` 页面，传递用户ID |
| 统一用户管理页 | 点击"批量删除" | 对选中行执行批量删除 |
| 侧边栏 | 点击"用户管理" | 路由跳转到 `/Home/user` |
